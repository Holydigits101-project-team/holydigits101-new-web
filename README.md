# Holydigits101 - Premium Web3 Education Platform

A cutting-edge, futuristic website for Holydigits101, transforming African education through Web3, blockchain, and digital skills integration.

## 🌟 Overview

This is a complete rebuild of the Holydigits101 website using modern web technologies (React, Vite, Tailwind CSS) with a premium, cyber-futuristic aesthetic inspired by Web3 platforms like Solana, a16z, and Apple.

## 🎨 Design Philosophy

- **Cyber-Futuristic + African Luxury**: High-end Web3 aesthetic with gold accents on deep black backgrounds
- **Glassmorphism**: Frosted glass effects, backdrop blur, and transparent gradients
- **Premium Animations**: Smooth Framer Motion transitions and GSAP scroll effects
- **Mobile-First**: Fully responsive across all devices
